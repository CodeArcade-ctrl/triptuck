# TripTuck

**Build your own packing list and track what is already in your bag.**

## Who it is for

A practical browser tool for this everyday task.

## Features

- Create a packing checklist and check items as you pack.
- Data is stored locally in your browser; there is no account, server, or external API.
- English and Dutch interfaces: open [`index.html`](../index.html) for Dutch.

## Run

Open `index.html` in a modern browser. No installation or build step is needed.

## Quick demo

Use fictional data to try the main action. Your changes appear in the overview and stay in local browser storage. Clear this page’s site data in your browser to reset everything.

## Privacy and limitations

Data stays in local browser storage and is not transmitted. It is not encrypted and may be deleted when browser data is cleared. The app is a small personal tool and does not sync between devices. No license file has been added.

## Technology

Vanilla HTML, CSS, and JavaScript. No external dependencies.
